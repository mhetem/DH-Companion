## What's new

### The player window

A second window for the screen your players can see: a TV, a monitor turned toward the
table, a projector. You run it from the new **Player window** section on the GM side.

- **It opens on the other screen, fullscreen.** With only one screen connected, it opens as
  a normal window instead. Double-click it or press F11 to toggle fullscreen, and Esc to
  leave fullscreen.
- **Each campaign keeps its own maps, scenes and text:**
  - **Maps** are always shown whole, so no edge of the map is ever cut off.
  - **Scenes** fill the screen, to set the mood for the tavern, the storm or the throne room.
  - **Text** is markdown on a dark page, with an optional backdrop: a letter, a riddle, a
    chapter title.
- **Images or looping video.** PNG, JPEG, WebP, GIF, MP4 and WebM are supported, so
  animated maps work too.
- **Nothing reaches the players until you press Show.** Each new picture fades in once it
  has fully loaded, and **Blank the screen** turns it black. The notes you keep on a map
  are never shown on the table.
- Files are copied into `~/DH-Companion/media` when you add them, so the originals can be
  moved or deleted.

### Good to know

- **Backups don't include the player window's images and videos.** They live in the `media`
  folder next to the database, so copy that folder along with a backup when moving to
  another computer. The library export leaves out maps, scenes and text too.
- **On Linux**, video needs GStreamer: `gstreamer1.0-plugins-good` for WebM and
  `gstreamer1.0-libav` for MP4. On Wayland desktops, apps can't choose where their windows
  open, so drag the player window onto the table's screen and double-click it.
- **Updating from 2.0.0:** the Windows installer, the macOS app and the AppImage can update
  themselves from **Settings & data → Check for updates → Update**. This is the first
  release 2.0.0 can install that way. If it doesn't work, the downloads below do the same
  job.
